# Iceberg Jelly 视觉与行为对齐验收计划

此文件以用户提供的 `Iceberg Jelly - Material Studies.html` 为参考规格，**不是**源代码授权证明；不得直接将该文件复制到公开仓库。

## 差距分析（2026-10-16）

| 子系统 | 参考作品 | 本仓库当前版本 | 后续改造 |
| --- | --- | --- | --- |
| 场景 | 完整极地海湾、冰川背坡与岩石地形 | 程序化冰山 + 冰晶 + 小岛 | 使用一致的地形与海岸高度场 |
| 水体 | 168×168 网格、深度/面通量/泡沫状态 | 57×57 局部阻尼波面 | 加入深度、岸线边界和泡沫 |
| 浮冰 | 体积采样求浮力、重心、转矩 | 简单漂浮动画、对象重叠分离 | 刚体质量、浮力采样、翻滚与碰撞 |
| 材质 | WebGPU WGSL、场景纹理、阴影、折射吸收 | WebGL MeshPhysicalMaterial | 专用半透明介质材质与预乘反射 |
| 船 | 航线、推进、唤醒波和撞冰 | 细节几何船模型 + 周期移动 | 轨迹与波/冰耦合 |
| 企鹅 | 数量、行为、投喂及岛屿位置 | 细化程序化模型 + 摇摆动画 | 行为状态机和投喂反应 |
| UI | 浅色杂志风格、功能分区、移动端抽屉 | 浅色工作台与配置面板 | 独立的创作/演示模式 |

## 本轮已提交
- `src/studio-assets.mjs`: 程序化冰山、企鹅、船、极地微缩底座
- `src/wave-sim.mjs`: 可以注入扰动的阻尼波面模拟
- `index.html`: 轻量摄影棚视觉主题、材质与灯光、点击水面触发局部波浪
- `tests/wave-sim.test.mjs`: 波场有限值与无效输入测试
- `.github/workflows/qa.yml`: Node + Playwright 自动测试和截图归档

## 高保真后续门禁
1. 获取参考作品同样相机角度的截图，保留原始尺寸与环境。
2. 自动渲染相同分辨率、同一个摄像机的本项目截图。
3. 比较轮廓、构图、色彩、冰雪材质、水面法线、阴影和动态反馈。
4. 记录运行环境、WebGPU/WebGL 回退、平均帧率、错误日志。
5. 用户人工确认符合视觉目标才标记视觉案例 PASS。

## 不应误判
- 模块提交、语法检查、单元测试与自动截图不等于视觉对齐。
- 当前不是完整的 WebGPU 水体或冰块浮力求解。
- v1.0 的九项强制验收仍按 `docs/ACCEPTANCE_V1.md` 执行；任何未执行测试维持 NOT RUN。
