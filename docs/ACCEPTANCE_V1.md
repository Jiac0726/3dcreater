# AI Scene Studio v1.0 — 九项强制验收门禁

状态：**验收标准已确定，实际测试尚未执行**。发布规则：9/9 PASS 才能标记 v1.0 正式版。NOT RUN、BLOCKED、FAIL 都不是 PASS。

| ID | 验收项 | 可重复测试 | 必须保存的证据 |
|---|---|---|---|
| AC-01 | 一句话生成不同场景 | 输入冰山、火山岛、果冻实验室三组描述；验证 SceneSpec 对象类型和位置的差异，不只是换颜色 | 3 份 SceneSpec、生成日志、截图 |
| AC-02 | ≥10 种对象及 ≥5 种材质 | 创建每一种对象和材质，验证构造成功、材质实际绑定、无异常 | 对象/材质清单、单元测试、截图 |
| AC-03 | 拖拽、点击、碰撞、动画 | 在浏览器自动触发每种交互，断言对象状态发生预期变化 | Playwright trace、交互视频、断言报告 |
| AC-04 | 自然语言增删改 | 对已有场景依次新增、删除、修改对象，验证未涉及对象保持不变 | 编辑前后 SceneSpec diff、测试记录 |
| AC-05 | 撤销、重做、保存、打开 | 编辑→撤销→重做→保存→重新打开，对序列化状态做深比较 | 状态快照、存取与历史测试 |
| AC-06 | 桌面浏览器实时预览 | Chrome 与 Edge 目标版本下正常渲染、操作，无崩溃；记录性能采样 | 浏览器版本、截图、性能/控制台日志 |
| AC-07 | 自动 QA | 自动启动生成项目，检查页面错误、控制台、截图、交互断言；故意注入失败确认能检出 | CI 工作流、PASS/FAIL 报告、失败样本 |
| AC-08 | 可独立运行的 HTML | 导出→断开开发服务器→以静态文件方式启动；主要场景与交互均可用；若声明离线版须断网复验 | HTML 文件、启动日志、离线/联网结果 |
| AC-09 | 三案例视觉和功能验收 | 冰山果冻、火山岛、果冻实验室分别依据事先确定的参考效果和功能清单执行人工+自动检查 | 参考图、实际截图、逐例测试单、验收签字/确认 |

## 发布约束
1. PR 检查对 AC-01 ~ AC-08 给出机器可读结果；AC-09 需人工确认记录。
2. 任一项 FAIL/BLOCKED/NOT RUN 时，版本只可标记 alpha/beta/RC，不可宣称 v1.0 验收通过。
3. 每项记录：测试日期、Git SHA、运行环境、操作者、结果、证据路径、已知问题。
4. 不允许用源码存在或语法检查通过替代浏览器运行验收。
5. 回归测试必须覆盖三个案例和独立 HTML 导出。
